# Feature roadmap

## Next milestone — 1.1 "Second Opinion"

- Cross-browser verification pass on real Firefox, Safari (macOS + iOS) and Android Chrome devices.
- Optional ambient music track (Web Audio, generative) with its own on/off setting.
- Save export/import (copy a code) so players can move progress between browsers.
- Screen-reader walkthrough with NVDA and VoiceOver; tune live-region verbosity per level.

## Later

- A "Narrator commentary" replay mode where Bossworth reacts to your best runs.
- Level editor using the same data format as `js/levels/*.js`.
- Localisation (all strings already live in data files; the UI needs a string table).
- Installable PWA with a service worker for offline install from a hosted copy.
- Daily "instruction of the day" micro-puzzle.

## Ideas parked

- Online leaderboards (conflicts with the no-network design goal).
- Multiplayer "two narrators" mode.
